# Análise de Dados - Xbox Game Pass Subscriptions

Este repositório contém uma análise detalhada das vendas e renovação dos planos do Xbox Game Pass, com foco na identificação de padrões de comportamento dos assinantes e performance financeira.

## 📊 Objetivo do Projeto

Analisar o desempenho das assinaturas do Xbox Game Pass para identificar:
- **Taxas de renovação automática** por categoria de plano
- **Planos com maior retenção** de assinantes
- **Comparativo entre renovação vs. não renovação**
- **Desempenho financeiro mensal** com base no faturamento líquido

## 🔍 Métricas Principais Analisadas

### 📈 Análise de Renovação
- **Total de Renovações Automáticas**: 148
- **Taxa de renovação por plano** (Annual, Monthly, Quartet)
- **Comparativo entre categorias**: Batary Season Pass vs Minecraft Season Pass
- **Identificação dos planos com maior retenção**

### 💰 Análise Financeira
- **Faturamento Líquido Total 2024**: R$ 3.880,00
- **Receita Líquida**: R$ 7.633,00
- **Performance mensal** do faturamento
- **Análise de receita por tipo de plano e assinatura**

## 🛠️ Tecnologias Utilizadas

- **Excel** para criação do dashboard
- **Análise de dados** para insights estratégicos
- **Visualização de dados** para apresentação clara dos resultados

## 🎯 Insights Gerados

O dashboard permite identificar:
- **Planos com maior taxa de renovação automática**
- **Meses com melhor performance financeira**
- **Tendências de comportamento dos assinantes**
- **Oportunidades para aumentar a retenção**

## 💡 Aplicações Práticas

- **Otimização de campanhas** de retenção baseada nos planos com maior renovação
- **Alocação estratégica** de recursos para os planos mais lucrativos
- **Previsão de receita** baseada em padrões históricos
- **Desenvolvimento de promoções** para planos com menor taxa de renovação
